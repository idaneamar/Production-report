📨 חיבור המייל של החברה (Outlook) למערכת

מגדirים פעם אחת שתי "זרימות" ב-Power Automate של מיקרוסופט. נכנסים עם חשבון ה-Outlook של החברה אל https://make.powerautomate.com

זרימה 1 — קליטת דוחות נכנסים

  1. Create ← Automated cloud flow ← בחר טריגר "When a new email arrives (V3)" (Office 365 Outlook).
  2. בטריגר: פתח Advanced options ← Include Attachments: Yes. אפשר לסנן לפי תיבה/תיקייה.
  3. הוסף פעולה Condition: Subject ← contains ← מילת הזיהוי של הדוח (למשל "דוח ייצור"). אפשר להוסיף OR לכל מילות הזיהוי מהחוקים בלשונית ניהול.
  4. בענף If yes: הוסף Apply to each על Attachments, ובתוכו פעולה HTTP:
    Method: POST
    URI: https://dddczmvjfokcbibeahyn.supabase.co/functions/v1/report-inbox
    Headers: x-inbox-secret = הסוד שיצרת בלשונית ניהול · Content-Type = application/json
    Body:
    { "subject": @{triggerOutputs()?['body/subject']}, "sender": @{triggerOutputs()?['body/from']}, "filename": @{items('Apply_to_each')?['name']}, "contentBase64": @{items('Apply_to_each')?['contentBytes']} }
  5. שמור. מעכשיו כל דוח שמגיע במייל יופיע בלשונית דוחות נכנסים באפליקציה.

זרימה 2 — שליחת תוצאות מהמערכת

  1. Create ← Instant cloud flow ← טריגר "When an HTTP request is received".
  2. ב-Request Body JSON Schema הדבק:
    {"type":"object","properties":{"to":{"type":"string"},"subject":{"type":"string"},"html":{"type":"string"},"attachments":{"type":"array","items":{"type":"object","properties":{"Name":{"type":"string"},"ContentBytes":{"type":"string"}}}}}}
  3. הוסף פעולה "Send an email (V2)" (Office 365 Outlook):
    To: to (מהטריגר) · Subject: subject · Body: html (החלף ל-HTML במתג הקטן)
    Advanced ← Attachments: הוסף פריט עם Name = item()?['Name'], Content = item()?['ContentBytes'] (בתוך Apply to each על attachments)
  4. שמור — תופיע כתובת URL בטריגר. העתק אותה והדבק בלשונית ניהול ← "שליחת תוצאות" ← שמור.
  5. בדיקה: בלשונית ניהול לחץ "✉ שלח מייל בדיקה אליי".
חשוב: את הסוד (x-inbox-secret) יוצרים בלשונית ניהול ← "🔑 צור סוד חיבור" ומעתיקים מיד ל-Flow. אם הסוד אבד — צור חדש ועדכן ב-Flow.
